# Skill Series Overview

This table summarizes the purpose, workflow, inputs, and outputs of the skills shipped with the project. Detailed rules remain in each skill's own `SKILL.md` and references.

| Skill | Purpose | Main workflow | Inputs | Outputs |
| --- | --- | --- | --- | --- |
| `planner-core` | Convert a pollution-analysis request into a short executable plan with suitable `tool_hint` and optional `skill_hint` values. | Read request and context; split into non-overlapping steps; select domain tools and skills; preserve time and pollutant constraints. | Current request, recent dialogue, tool results, memory, time range, pollutant, plot, warning, or RSM requirements. | Executable plan steps, tool hints, skill hints, and retained conversation variables. |
| `executor-core` | Execute one planned step, absorb tool results, and return a concise evidence-based conclusion. | Reuse context; follow the selected domain skill; call the named tool; report failures without inventing evidence. | One plan step, tool and skill hints, context, paths, dates, pollutants, and parameters. | Step conclusion in the user's language, real artifact paths, and explicit gaps or failures. |
| `cmaq-forecast-qa` | Answer numerical questions over CMAQ NetCDF forecasts, including trends, exceedances, hotspots, and meteorological drivers. | Locate and inspect CMAQ files; map indicators; run extraction or question analysis; summarize auditable CSV and JSON outputs. | CMAQ folder or file, question, indicator, optional time range, threshold, and output folder. | Hourly/daily CSVs, hotspot CSV, JSON summary, and a data-grounded answer. |
| `cmaq-plot-data` | Generate CMAQ pollutant time series, spatial maps, or both. | Resolve variables; apply the requested time range; render one or both plot types; read the plot summary. | CMAQ folder, metric, plot type, optional timestamps/range, and output folder. | PNG figure, JSON plot summary, optional time-series CSV, and an explanation in the user's language. |
| `chengdu-cmaq-forecast-correction` | Diagnose and correct Chengdu PM2.5/O3 CMAQ forecasts using Windy meteorology, observations, and expert rules. | Build meteorological prior; assess spatial and temporal credibility; choose one correction path; nudge, smooth, plot, and report. | CMAQ data, pollutant, meteorological prior, optional observations/stations, expert rules, and output folder. | Diagnosis, corrected station and city CSVs, factors, explanations, assessment, and figures. |
| `chengdu-pollution-alerming` | Calculate China AQI and assess Chengdu warning levels under the 2024 emergency plan. | Normalize concentrations; calculate IAQI/AQI; evaluate the daily forecast sequence; retrieve the matching response section; distinguish automated advice from official release. | Pollutant concentrations, `forecast_daily_aqi` or `forecast_days`, dominant pollutant, and optional official context. | AQI, primary pollutant, warning/response category, rationale, response measures, and consultation caveat. |
| `chengdu-pollution-report` | Produce a complete Chengdu PM2.5/O3 pollution-process report. | Confirm scope; assemble warning, CMAQ, observation, and Windy evidence; analyze mechanisms; separate official and analytical measures; integrate the report. | Time range, PM2.5/O3, report type, available model/observation/source data, meteorology, and format. | Markdown or optional DOCX report with assessment, warning, meteorology, mechanisms, measures, figures, and uncertainty. |
| `run-rsm-reduction` | Run local DeepRSM emission-reduction scenarios and estimate PM2.5 improvement across 12 regions. | Parse scope and reductions; write a `caseN` row; run the PM chain; read `Dpm25` output; report `baseline - scenario`. | Scenario, case number, grid/region, pollutant factor, reduction percentage, and optional dry-run flags. | Updated case rows, RSM result files, 12-region improvement estimates, read months, and interpretation caveats. |
